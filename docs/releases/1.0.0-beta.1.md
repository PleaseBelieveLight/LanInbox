## Highlights

- Send text, links, code snippets, images, and files between Android and Windows on a local network.
- Pair by QR code or manual entry and transfer over HTTPS with paired certificate verification.
- Reconnect to a saved computer after restarts or a local IP address change.
- Share text from Android apps and drag a file into the Windows send area.

## Downloads and requirements

- Android 7.0 (API 24) or later: `LanInbox-1.0.0-beta.1-android.apk`.
- Windows x64: `LanInbox-1.0.0-beta.1-windows-x64.msi`. The Java runtime is included.
- Connect both devices to the same local network. Allow camera/local-network permissions on
  Android and private-network access through Windows Firewall when prompted.
- Compare downloaded files against `SHA256SUMS.txt`. `BUILD-INFO.txt` identifies the source
  commit and installer versions; `ANDROID-SIGNING-CERTIFICATE.txt` records the APK signer.

## Installation and upgrades

Install the APK on Android and the MSI on Windows, open both apps, then choose **Connect phone**
on Windows and **Scan to connect** on Android.

An existing Debug APK signed with another key must be uninstalled before installing this
Release APK. Save needed data first: uninstalling removes Android app data and pairing.
Older Windows verification builds may also require a one-time uninstall. Later releases retain
the release signing key and Windows installation identity to support upgrades.

## Known limitations

- Keep LanInbox in the foreground on Android while receiving transfers from Windows.
- Discovery can be blocked by guest Wi-Fi, network isolation, or firewall rules. Manual pairing
  still requires direct network access between the devices.
- The Windows installer is currently unsigned.
